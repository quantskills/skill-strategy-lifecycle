# 策略生命周期控制

这是一个符合 QuantSkills `skill-template` 目录规范的中文研究技能项目。

它回答的问题是：在固定上游模型、信号和风险统计后，策略降权、冷却、退役与再激活规则，是否比持续持有更适合样本外运行。

项目只使用冻结输入，不修改 Q8 因子或模型。状态机按点时信息重放，输出三组核心对照、机会成本和逐期状态账本。

## 运行方式

平台级运行应从项目版本调用：

```text
python evo_entry.py
```

本仓库不包含私有 Q8 数据、平台令牌、账户信息或本地运行结果。研究输入来源为用户提供的冻结 Q8 版本；参数、费用、冷却、退役和恢复门槛以冻结配置为准。结果仅供研究和教育使用，不构成投资建议，也不承诺收益。运行前按 [输入合同](references/input-contract.md) 将冻结输入挂载到项目环境。

## 主要文件

- `evo_entry.py`：统一运行入口；
- `run_all.py`：测试、研究、诊断、扩展验证和报告生成；
- `state_machine.py`：生命周期状态机；
- `results/summary.csv`：三组对照收益；
- `results/state_ledger.csv`：状态账本；
- `results/opportunity_cost.json`：停用机会成本；
- `results/report.html`：中文展示报告。

## 研究限制

研究结果依赖冻结数据、成本口径和成熟标签。退役消融没有改变交易路径时，退役只能解释为治理标签。没有独立未来确认集时，不把回顾性结果写成稳定性或实盘证明。

数据来源为用户提供的冻结 Q8 研究输入；本项目不自动验证数据授权、历史发布时间或可成交性。参数、费用、冷却、退役和恢复门槛写入冻结配置；结果依赖这些假设和区块抽样统计。项目仅供研究与教育使用，不构成投资建议，也不承诺收益。
