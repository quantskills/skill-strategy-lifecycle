# E6 内置策略副本

`q8_engine_v2.py` 是 E6 为了减少运行时耦合而保存的策略引擎副本。它来自本项目使用的 Q8 策略实现，保留原有的评分、选股、交易成本、四相位账户和收益计算口径；E6 没有在复制过程中重训模型或修改策略逻辑。实际输入由 EVO 运行时的 Pandadata 适配器生成。

E6 运行时从本目录加载代码，再把 `E6_Q8_ROOT` 指向的 Pandadata 运行时输入和配置注入给该副本。这样 E6 不需要动态导入 Q8 项目中的 Python 文件；输入来源、日期范围和哈希写在运行目录的 `runtime_manifest.json` 中。

来源文件、复制时间、源文件指纹和 E6 副本指纹见 `provenance.json`。如果修改该文件，必须重新生成指纹并重新审核研究结果。
