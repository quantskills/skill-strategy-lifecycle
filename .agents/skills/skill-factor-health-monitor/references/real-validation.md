# 真实传统因子验收

使用与 `factor-rl-weighting` 相同的五个传统因子面板，覆盖 2020-08-18 至 2026-07-09，共 799 只股票。因子均整体滞后一交易日，避免使用决策日尚不可得的信息。

最新一期结果中，60 日动量为红灯，健康度 8，衰退概率约 92%；其余四个因子为绿灯。对衰退阈值、卡尔曼过程方差和 CUSUM 阈值共 27 组扰动后，红灯比例范围为 0% 至 20%，按当前稳定性规则判定可接受。

这组数据没有人工标注的真实失效日期，且部分因子的基准 IC 本来低于 0.02，因此不能用于证明“至少提前 5 个交易日”。输出应解释为健康监控结果，不是预警准确率证明。

结果文件位于 `outputs/real-traditional/` 和 `outputs/real-traditional-robustness/`。
