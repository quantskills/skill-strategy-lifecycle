# 方法说明

每日 IC 是同一交易日因子值与下一交易期收益的截面 Spearman 相关。滚动 IR 为窗口内 IC 均值除以样本标准差。

CUSUM 先用 120 日基准估计均值和波动，再累计负向标准化偏差。漂移项默认 0.25，阈值默认 5；报警后统计量归零，以便发现新的变化。

状态空间模型为：

```text
true_ic[t] = true_ic[t-1] + process_noise
observed_ic[t] = true_ic[t] + observation_noise
```

卡尔曼滤波逐日更新后验均值和方差。衰退概率定义为 `P(true_ic < baseline_ic - 0.02)`。默认概率低于 50% 为绿，50%–80% 为黄，80% 以上或当日出现 CUSUM 报警为红。

默认状态噪声方差为 `1e-6`，观测噪声方差为 `2.5e-3`，目的是让单日 IC 噪声不会轻易触发状态反转。历史验收还要求衰退概率连续十日均值超过阈值，或由 CUSUM 与至少 50% 的短期衰退概率相互印证。

这些阈值需要在训练案例中确定，再冻结到独立验证案例。不能用同一批失效因子一边调阈值、一边宣称提前量达标。
