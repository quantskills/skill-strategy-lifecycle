# EVO 平台运行证据要求

平台运行时应保存：

- 项目版本或提交号；
- 平台运行编号；
- 输入文件清单和 SHA256；
- 在 `project/` 中执行 `python evo_entry.py` 的原始控制台输出；
- `runs/evo/input.json` 与 `runs/evo/output.json`；
- `results/` 输出文件清单和散列；
- 平台显示的成功或失败状态。

只下载 HTML 或 CSV 不能单独证明平台运行成功。平台回执与项目输出应逐项核对。

本项目已保存一份用户提供的 EVO 成功页面截图及其转录，位于 [evo-evidence](evo-evidence/)。截图可见：8 个步骤全部完成、45 个输出文件、验收 15/15 项通过和多头对照摘要。截图未显示独立平台运行编号、完整控制台原文、输入指纹和输出散列，因此这些字段仍应在 EVO 导出完整回执后补充。
