# 输入合同

项目级运行环境需要提供冻结策略输入。建议由平台任务挂载或由受控数据资产提供，不把私有数据提交到公开仓库或技能仓库。

## 必需字段

| 输入 | 说明 |
|---|---|
| 策略逐期收益 | 至少包含日期、策略标识、毛收益、成本和净收益 |
| 成熟健康指标 | 只能使用在该日期已经成熟的 IC、回撤、换手或风险统计 |
| 交易或信号记录 | 用于核对状态变化是否产生实际暴露变化 |
| 冻结配置 | 费用、观察窗口、冷却长度、退役门槛、恢复门槛 |
| 时间边界 | 训练段、评估段和未来确认段，运行前固定 |

## 运行前检查

- 输入文件指纹与冻结清单一致；
- 日期单调且无重复；
- 状态输入不包含未来收益；
- 成本字段可重算净收益；
- 评估期没有事后挑选停用日期；
- 缺失数据和未成熟标签不会自动填成健康信号。

输入合同不证明数据真实、已获授权或可成交。研究报告必须保留数据来源、参数、费用假设和限制。
